# Cliente web del ejercicio 2

Cliente Vue independiente para la API Flask del directorio contiguo `../backend`. La consulta de juegos es pública. Para añadir, editar o eliminar, introduce el `ADMIN_API_TOKEN` configurado para Flask.

Desde esta carpeta:

```powershell
npm install
npm run dev
```

La URL base por defecto es `http://127.0.0.1:5000/api`. Para cambiarla, define `VITE_API_BASE_URL` antes de iniciar Vite.
